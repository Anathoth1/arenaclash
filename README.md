# ⚔️ Arena Clash

Um jogo de estratégia em tempo real inspirado em Clash Royale, desenvolvido com HTML5 Canvas e JavaScript puro.

## 🎮 Como Jogar

1. Clique em **BATALHAR** para iniciar
2. Selecione uma fase desbloqueada
3. Escolha uma carta clicando nela
4. Clique na área verde (sua metade do campo) para posicionar a tropa
5. Destrua as torres inimigas para vencer!

## ✨ Funcionalidades

- 🗺️ **10 Fases** com dificuldade progressiva
- 🃏 **20+ Cartas** com raridades diferentes (Comum, Rara, Épica, Lendária)
- 💰 **Sistema de Ouro** - Ganhe ouro ao vencer batalhas
- ⬆️ **Upgrades** - Melhore suas cartas com ouro
- ⚡ **Double Elixir** - Elixir regenera 2x mais rápido nos últimos 60 segundos
- 😀 **Emotes** - Comunique-se durante a batalha
- 🎨 **Gráficos HD** - Efeitos visuais avançados com partículas e animações

## 🃏 Tipos de Cartas

| Raridade | Exemplos |
|----------|----------|
| Comum | Cavaleiro, Arqueira, Esqueletos, Bola de Fogo |
| Rara | Gigante, Mosqueteira, Valquíria, Bombardeiro |
| Épica | Bruxa, Príncipe, Mago, Dragão Bebê |
| Lendária | Golem, PEKKA, Mega Cavaleiro, Sparky |

## 🛠️ Tecnologias

- HTML5 Canvas
- CSS3 com animações
- JavaScript ES6+
- LocalStorage para salvar progresso
